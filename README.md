# Kedi Miyav Bilgelik Motoru 🐱

## Bu Nedir?

Bu, insanlık tarihinin en büyük dilbilim başarısıdır. Kedilerin miyavlarını derin, felsefi Türkçe bilgeliklere çeviren, ve insan metinlerini tamamen anlamsız ama "derin" miyav dizilerine dönüştüren bir motordur.

**Ciddiye almayın.**  
**Ama ciddiye alın.**  
**Çünkü çalışıyor.**

## Nasıl Çalışır?

1. Python 3 yükleyin (kediler yüklemedi).
2. `python miyav_motoru.py` yazın.
3. Bir şey yazın, kedi miyavlasın.
4. "bilgelik" deyin, kedi size hayat dersi versin.
5. "quit" ile çıkın, kedi sizi yargılasın.

## Özellikler

- Gerçekten çalışır (test edildi, kedi onayladı).
- Rastgele bilgelik üretir (bazıları çok derin, bazıları sadece miyav).
- Sonsuz döngüde çalışabilir (ta ki siz sıkılana kadar).
- Gizli mesajlar içerebilir (ama gizli, o yüzden bulamazsınız).

## Kullanım Örneği

```
Bir şey yaz: Merhaba dünya
Miyav çevirisi: miyaav → mrrr miyav
Kedi yorumu: Sabah çayı demlemeden güne başlama, yoksa gün seninle başlamaz.
```

## Uyarı

Bu motoru kullanarak alınan kararlardan kediler sorumlu değildir.  
Eğer hayatınız değişirse, teşekkür edin. Değişmezse de miyavlayın.
